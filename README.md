# 🚀 Financial Fraud Detection – Data Engineering Pipeline

## 📌 Project Overview

An end-to-end Data Engineering pipeline designed to process
financial transaction data and support fraud detection.

The project applies modern data engineering practices
using Python, ETL processes, and Medallion Architecture.

---

## 🏗️ Data Architecture

The project follows the Medallion Architecture:

🥉 **Bronze Layer**
- Raw data ingestion.
- Initial data storage.

🥈 **Silver Layer**
- Data cleaning and preprocessing.
- Duplicate detection and handling.
- Data quality checks.
- Feature engineering.

🥇 **Gold Layer**
- Processed and structured datasets.
- Data prepared for analytics and downstream use.

---

## 📊 Dataset Description

- Dataset: Credit Card Fraud Detection (Kaggle)
- Total Transactions: 284,807
- Fraudulent Transactions: 492
- Target: Class (0 = Legitimate, 1 = Fraudulent)

---

## ⚙️ Data Engineering Workflow

- Data ingestion and inspection.
- Data cleaning and transformation.
- Duplicate detection and removal.
- Handling missing and inconsistent values.
- Feature engineering.
- Data quality validation.
- Structured data preparation.

---

## 🧠 Feature Engineering

- Log transformation for transaction Amount.
- Transaction frequency features.
- Feature scaling using StandardScaler.
- Handling class imbalance using SMOTE.
